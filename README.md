# personal-jervis

iPhoneのホーム画面から使う、自分専用のAIアシスタント「Jervis」です（最小構成）。

- 会話はGoogleの **Gemini API（無料枠）** で動きます。サーバーは不要です。
- APIキーと会話履歴は、使っているスマホのブラウザの中だけに保存されます（リポジトリには入りません）。
- 音声入力はキーボードのマイクボタン、または画面の 🎤（対応ブラウザのみ）で使えます。
- 🔇 / 🔊 ボタンで、返答の読み上げをオン・オフできます。
- 📝 **メモ・ToDo**: 「明日の点呼で〇〇を伝える、覚えておいて」「〇〇は終わった」と話しかけると、Jervisがメモを追加・完了します。「今日やることは？」と聞けば一覧から答えます。📝ボタンから手で追加・チェック・削除もできます（メモも端末内だけに保存）。
- 🗓 **今日のメモ**: その日はじめて開いたとき、期限切れ・今日・明日・期限なしのメモをまとめて表示します（AIは使わないので無料枠を消費しません）。🔊で読み上げもできます。

## 使い始める手順（iPhoneだけで完結）

1. **APIキーを取る**: Safariで <https://aistudio.google.com/apikey> を開き、Googleアカウントでログインして「APIキーを作成」を押します。表示されたキーをコピーします。
2. **アプリを開く**: 公開したURL（下の「公開方法」を参照）をSafariで開きます。
3. **キーを設定する**: 右上の ⚙️ を押し、APIキーを貼り付けて「閉じる」を押します。
4. **ホーム画面に追加**: Safariの共有ボタン →「ホーム画面に追加」を選ぶと、アプリのように使えます。

## 公開方法

このアプリは静的ファイルだけで動くので、無料で公開できます。

- **GitHub Pages**: 無料プランでは、リポジトリを公開（Public）にする必要があります。コードの中にキーや個人情報は入っていません。
  - 設定方法: Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にします。
- **Cloudflare Pages など**: 非公開のリポジトリのまま無料で公開できますが、初期設定に少し手間がかかります。

## 注意

- 無料枠では、送った内容がGoogleのサービス改善に使われる場合があります。**乗務員の個人情報や社外秘の情報は入力しないでください。**
- 無料枠には回数の上限があります。上限に達したら、時間をおいてから使ってください。
- 「モデルが見つかりません」と出たら、⚙️ の「一覧取得」で使えるモデルを選び直してください。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | 会話、設定、音声の処理 |
| `memo.js` | メモ・ToDoの保存と、会話からの操作 |
| `sw.js` | オフライン用キャッシュ |
| `manifest.webmanifest`, `icons/` | ホーム画面用アイコン |
